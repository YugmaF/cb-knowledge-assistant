## Summary

SEV2 incident. On 2026-02-17, after a firmware upgrade of hardware security module (HSM) node hsm-02 from firmware 7.3.1 to 7.4.0, PIN verification failed for about one third of card transactions from 02:15 to 06:40.

## Impact

The HSM firmware issue declined PIN-based card and ATM transactions for about 6,900 customers. Contactless payments below the PIN limit and e-commerce transactions were not affected.

## Timeline

- 01:30 Firmware 7.4.0 applied to hsm-02 in a planned change.
- 02:15 Alert: PIN verification error rate 33 percent.
- 03:00 SEV2 declared; errors traced to requests routed to hsm-02 only.
- 05:50 hsm-02 removed from the HSM load balancer pool.
- 06:40 hsm-02 rolled back to firmware 7.3.1 and verified; incident resolved.

## Root Cause

The HSM firmware 7.4.0 disabled by default the legacy variant key format that the bank's zone PIN keys still use; the change was noted in the vendor release notes. The HSM upgrade was tested only on a lab HSM without production-like key formats, and the change was classed as standard, so it skipped change advisory board review.

## Resolution

The HSM incident was resolved by removing hsm-02 from service and rolling its firmware back to 7.3.1. No keys were exposed.

## Action Items

- Migrate zone PIN keys to key block format before any 7.4.x upgrade (owner: Dilini Gunawardena, due 2026-06-30).
- Build an HSM staging environment with production-like key formats.
- Classify HSM firmware changes as normal changes requiring CAB approval.
