## Summary

SEV1 incident. On 2026-08-25, the August salary day, payments-ledger connection pool exhaustion caused a payments outage from 08:20 to 11:40. This was the fifth payments-ledger connection pool exhaustion incident since May 2025.

## Impact

The August salary day outage affected about 28,000 customers whose transfers, InstaPay and bill payments failed or were delayed. It was reported to the regulator as a major operational incident.

## Timeline

- 08:20 Alert: PgBouncer client wait queue above 2,000.
- 08:35 SEV1 declared.
- 09:10 New InstaPay bulk payee validation feature found issuing one query per payee.
- 10:30 Bulk payee validation disabled by feature flag.
- 11:40 Error rate normal; incident resolved.

## Root Cause

The payments-ledger connection pool exhaustion recurred because a new InstaPay bulk payee validation feature issued one ledger query per payee (an N+1 query pattern), each holding a PgBouncer connection. The salary-day load test did not include the new feature, so the PgBouncer pool of 400 server connections was exhausted despite the read replica.

## Resolution

The bulk payee validation feature was disabled and payments-ledger recovered. The feature was rewritten to use a single batched query.

## Action Items

- Set a connection budget per feature and review new ledger queries (owner: Daniel Okafor).
- Include every new feature in the salary-day load test (owner: Tharindu Jayasuriya).
- Commission a payments-ledger capacity redesign (owner: Hannah Lindqvist, due 2026-10-31).
